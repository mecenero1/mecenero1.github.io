# Портфолио mecenero

Страница со всеми работами: обложка, короткое описание и ссылка для каждого проекта.

Адрес: https://mecenero1.github.io/portfolio/

Этот же список показывается на главной странице визитки в разделе «Мои работы»: там выводятся последние четыре работы. Поэтому новую работу достаточно добавить один раз, сюда.

## Как добавить новую работу

### Попросить Claude

Напишите в чат: «Добавь в портфолио новый сайт», дайте ссылку на сайт и на репозиторий `mecenero1/mecenero1.github.io`. Claude сделает скриншоты, обложку и описание и загрузит всё сюда.

### Самому через сайт GitHub

1. Сделайте два скриншота нового сайта: на компьютере (окно 1440×900) и на телефоне (экран 390×844).
2. Сделайте из них картинки скриптом:

   ```
   python3 portfolio/tools/make_cover.py <id> "#цвет" desktop.png phone.png
   ```

   В папке `portfolio/img` появятся `<id>.webp` (обложка) и `<id>-phone.webp` (экран телефона).
   Здесь `<id>` — короткое имя латиницей, например `vishnya`, а цвет — фон обложки, например `"#EFE5DF"`.
3. Загрузите обе картинки в папку `portfolio/img`: откройте её на GitHub и нажмите Add file → Upload files.
4. Откройте `portfolio/works.js`, нажмите на карандаш и допишите в конец списка новый блок по образцу остальных. Не забудьте запятую после предыдущего блока.
5. Нажмите Commit changes. Через минуту-две сайт обновится сам.

Порядок блоков в `works.js` — это порядок работ на странице.

Две необязательные пометки в блоке работы:
- `fan: false` — не показывать работу в веере на первом экране портфолио;
- `home: false` — не показывать работу в разделе «Мои работы» на главной странице визитки.

## Что в папке

| Файл | Что это |
|---|---|
| `index.html` | Страница портфолио |
| `works.js` | Список работ — единственное, что нужно править при добавлении |
| `img/` | Обложки, экраны телефонов и логотип |
| `fonts/` | Шрифты Inter, лежат рядом с сайтом без внешних сервисов |
| `tools/make_cover.py` | Скрипт, который делает обложку из двух скриншотов |
