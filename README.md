# mecenero — разработка сайтов

Сайт-визитка: https://mecenero1.github.io/

Основа сайта — файл `index.html` (шрифты и графика встроены). Раздел «Мои работы» берёт данные из папки `works`.

## Как добавить работу в раздел «Мои работы»

1. Положите в папку `works` обложку `<id>.webp` размером 1600×1000, где `<id>` — короткое имя латиницей, например `vishnya`.
2. Откройте `works/works.js` и допишите в список новый блок по образцу остальных: название, тип, пара предложений, что сделано и ссылка. Не забудьте запятую после предыдущего блока.
3. Сохраните изменения. Через минуту-две сайт обновится сам.

Порядок блоков в `works.js` — это порядок работ на сайте.
